# Quick Summary: 260910-002 — Right panel collapse persistence

**Task:** Fix the right-side realtime panel. When collapsed, it disappears from the side and cannot be reopened; the rail entry must remain consistent.

## Problem

Clicking the header **X** on the MITS stations panel calls `closeRightPanel(id)`, which removes the panel from `visibleIds`. With no visible `replace-style` panel, `replaceStylePanelId` becomes `null` (`useReplaceStylePanelId` in `useRightPanels.ts`) and the host's style-side `SharedSidebar` — the 44px right rail — unmounts entirely (DesktopShell mounts it only when `replaceStylePanelId` is truthy). The "REAL-TIME" entry vanishes and there is no way to reopen the panel from the side.

## Root cause

Closing = removing the panel. No mechanism kept a closed panel reopenable from the rail.

## Fix

A new `persistent` flag on `GeoLibreRightPanelRegistration`:

1. **`packages/plugins/src/types.ts`** — added `persistent?: boolean` (documented: host ×  collapses the panel to its rail entry instead of fully removing it, so it always stays reopenable from the side rail).
2. **`apps/geolibre-desktop/src/components/panels/PluginRightPanel.tsx`** — the header X button now reads `getRightPanel(activeId)?.persistent`; when true it calls `collapseRightPanel(activeId)`, otherwise `closeRightPanel(activeId)`. Title/aria-label unchanged (no new i18n keys). Registry `closeRightPanel` keeps its true-close semantics for non-persistent panels (e.g. Browser).
3. **`packages/plugins/src/plugins/mits/index.ts`** — MITS `mits-telemetry-stations` panel registered with `persistent: true`.

True chevron collapse already retained the rail entry (`visibleIds` keeps the id); with persistence the X behaves the same, so both actions are now consistent.
